# Exact Demo Click Path

1. Run `start_demo.bat`.
2. Run `powershell -ExecutionPolicy Bypass -File demo/prepare_demo.ps1`.
3. Open `http://127.0.0.1:5173` and show **Dashboard**.
4. Open **Targets** and select **AegisScan Security Demo Lab**.
5. Open **Assessments**, select **AegisScan Local Demo Assessment**, and show authorization.
6. Open **Attack Surface**.
7. Select the demo assessment and click **Start Discovery**.
8. Wait for **Completed**, then show the discovered inventory.
9. Open **Scan Jobs** for the assessment.
10. Click **Generate Plan**.
11. Click **Run Assessment Scans**.
12. Click **View Raw Logs** on the completed Custom Rules job.
13. Show **Raw Output / JSON**, then **Execution Metadata**.

The Findings, Verification, Risk, and Reports pages are next-phase surfaces and must be described honestly if opened.
